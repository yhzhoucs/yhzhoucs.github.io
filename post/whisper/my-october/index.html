我的十月：修电脑、崩系统、灾祸与重建

苦难来源于一张网卡

之前在网上刷贴子的时候无意间看到一位跟我用相同笔记本电脑的老哥把他的电脑进行了系统地升级，换了网卡、内存、屏幕等，简直是一个忒修斯之船。看完这个贴子我立马萌生了给我自己的笔记本电脑换网卡的想法，原因就是一张不错的网卡也就 50 块，而且看网上的说法换上后提升非常大。

于是我立马开始着手操作，去某平台下单了一张 Intel 的 AX211 网卡。等 10 月 10 号网卡到货的时候，真正的悲剧开始了。

当天晚上，我兴冲冲地拆开笔记本电脑后盖，娴熟地主板断电，拆螺丝，一下就把之前的旧网卡拆了下来，然后装上新网卡，插上天线，开机。咦，电脑按开机键怎么一点动静也没有？然后我就意识到，糟了！

之后无论我是把原来的网卡换上去，还是多次拔插尝试，都没什么用。中间还把电脑无线网卡的天线接头给搞坏了，至此我彻底绝望。好在不插网卡就能正常开机，让我稍稍有一丝安慰，因为至少不是完全的主板短路。

颠沛流离的开始

第二天我就先是联系了戴尔的官方授权维修店，去那边师傅看一下直接狮子大开口，要我 600 块，仅仅是换一个天线。我拒绝后当天就没有再采取任何措施，因为下午有个会要开。因为电脑目前没网（我房间没有有线网络接口，所以只能通过无线网卡上网），所以开会也只能手机上简单说几句，弄得有些许尴尬。

第三天，我抱着试一试的态度，去找了一家非官方的修数码产品的店，还是看的某书推荐说不错才去的。师傅用专业的放大镜看了网线接口，然后又用专门的工具把网线接口中堵住的小铁圈给拿了出来。就在我以为松了一口气的时候，把网卡插上去还是没反应，师傅说可能是主板某个地方短路了，最坏的事情还是发生了。无奈之下就只能把电脑留在店里我独自一人离开。

接下来我就开始了长达一周的没有电脑的生活，当然，白天我可以用办公地方的电脑。这时候每天我都要在办公的地方待到很晚，晚上回来后也没有电脑用来娱乐。刚开始有点难以适应，回来后只能刷手机直到入眠，但后来我渐渐习惯了没有电脑的晚上。

我把之前淘的二手 cd 随身听翻了回来，给它加上两节5号南孚电池，又翻出之前淘的二手 cd 专辑以及一些自己刻录的 cd 。渐渐的晚上我开始长时间地与音乐相伴，一张专辑的时间在 40 分钟左右，完整地听完一张 cd 专辑与只挑其中喜欢的歌来听是截然不同的体验。我有一张 Bob Dylan 的精选集，里面收录了许多他最著名的歌曲，比如《答案在风中飘》和《像一块滚石》，这张专辑我特别爱听。

时不时我也把之前买的书翻出来，有计算机的也有文学的。计算机的主要是之前买的盗版《 Rust 程序设计》和自己找店打印装订的一本英文书《 Rust For Rustaceans 》，其实这两本我都有电子资源，但还是纸质书翻起来方便。有时候单纯去看这些书都有点意思，你会发现自己之前写的代码有多蠢，也会灵光一闪找到某个功能的简洁实现方法。我之前一直以为计算机专业相关的东西都是在实践中学习，看了别人的代码后自己才会写代码。现在想想真的是大错特错了。把一门语言的理论基础打牢固了，写代码的时候才会真正的得心应手，写程序最爽快的时候就是：你知道怎么写、要用哪些工具，而且最幸运的是你刚好会用这些工具（抽象的工具，无论是语言的特性、语法还是像 CMake 这样的实体的构建工具都算）。

时不时我就看文学书，袁越的《来自民间的叛逆》是对美国民歌历史的很好归纳，本来只在图书馆看，后面由于太喜欢终于还是自己买了本新的收藏。其他的就是反复读过的 Aldo Leoplod 的《沙乡年鉴》，我真的太喜欢这本书，带了它旅行了很多地方，有荒野也有城市，每到一个地方我都要想起书里的句子。最后就是梭罗的《瓦尔登湖》了，这本也是我最爱的书，今后还得花更多时间去体悟和思考里面的内容。

言归正传，这一周时间里我也多次催促店老板想让他加快点修复进度，后面说主板短路的问题已经解决，但插上网卡还是没反应。这个时候我就有些焦虑了。经过协商我还是决定直接用终级方案： USB 无线网卡。考虑到这些天老板一直没闲着，也跟我跟进过进展，没有功劳也有苦劳，所以我决定就在老板这店里买 USB 网卡，多少也算是我的心意。之后连同网卡和维持费共给了 68 块。感觉也还算正常，至少吊打戴尔官方的一个天线 600 块。

升级、再次沦陷

之后想着即使用 usb 网卡也不能让体验丢失太多，遂又在网上买了一个 100 多块的 usb 无线网卡（支持 wifi 7 ，听起来厉害就完事了）以及一个自供电的集线器，后面证明这个集线器真是买对了。

到货以后装配起来，下载速度达到了 50 MB/s ，居然是电脑没坏时候的两倍。这再来看无线网卡坏了也是好事，我都没料到原来网速还能翻倍。中间遇到的问题就是网卡老是自动重启，导致频繁断网，摸排之后发现是电脑 usb 口供电的问题，只要把 usb 网卡插到集线器上就行了。

想着最近想把所有的开发都转移到 Linux 上，我决定全部都用 wsl 开发。但这样一来内存空间就捉襟见肘了，代码写到后面电脑就会很卡。趁着双11大促，我又购入一张某国产 32GB 内存条，插到电脑上后总内存达到了 40 GB ，就在我满心喜欢的时候，问题出现了。每次一打开 wsl ，电脑立马死机。这个问题在我重装了 Windows 10 系统之后还是存在，以至于我都开始怀疑是不是内存条是坏的或者主板不支持这种大容量的内存条。

我在绝望中最后一次尝试了 Windows 11 ，装上后打开 wsl 发现问题居然神奇地消失了，看来这次我们的 Good Lord 是在眷顾着我的。

到这里，我这次的颠沛流离才算画上了句号。这篇文章就是我用最新的 Window11 系统里 wsl 中安装的 Emacs 写的。这个 Emacs 是我自己从源代码编译的，还颇有成就感，我为它安装了 emacs-rime 并加上的五笔86的输入方案。现在用起来很顺手，比 windows 上的 emacs 流畅太多太多。

后记

自从重新利用起 bittorrent 下载东西后，我像是打开了新世界一样，原来现今的 P2P 网络还在活跃着，能下载许多高清乃至蓝光的电影等。其实硬盘空间还是充足的，因为之前刚把坏的 1TB 机械硬盘换成了2TB 的新机械硬盘，但总感觉空间是越多越好 :) 于是我又在网上淘了二手的机械硬盘，60 块的 640GB 还要什么自行车。用之前闲置的一个机械硬盘盒装起来插到集线器上，电脑的存储空间又提升了。现在我的电脑存储空间接近 4TB ，想想换新电脑之前应该是够用了。

本来最后一段是想写一些从痛苦中领悟的道理以及一些在苦难中给我希望的东西，然而这篇文章已经是隔了太久之后的补完，所以那种心情已经完全消失不见了。现在的我即使硬写也写不出什么好的句子。

只能简单附上马友友的一段话来代表我这段时间思考的东西：

我一直问自己，音乐到底有什么用？如果人们吃不上饭、根本没有听音乐的心情，音乐的价值是什么呢？我每天都在自问。我不得不说，我们得创造价值，我们得确保这些价值真的存在。此时此刻，部分的价值是给出安慰，也不仅是安慰，是在安慰和治愈之间，更像是安抚灵魂。

这是一段我想用笔摘抄到本子上的话。
